# Fly Elsi - Static Website

A modern, responsive static website for Fly Elsi, a technology solutions company.

## Features

- **Responsive Design**: Works on all devices and screen sizes
- **Modern UI**: Clean, professional design with smooth animations
- **Multi-page Structure**: Complete website with multiple pages
- **Interactive Elements**: Smooth scrolling, form validation, hover effects

## Pages

- **index.html** - Homepage with hero section and featured products
- **about.html** - Company information, mission, vision, and team
- **products.html** - Product catalog with 6 featured products
- **product-xxx.html** - Individual product detail pages
- **news.html** - Latest news and articles
- **post-xxx.html** - Individual article detail pages
- **customers.html** - Customer testimonials and partner showcase
- **contact.html** - Contact form and company information
- **privacy.html** - Privacy policy document

## Technologies

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with Flexbox and Grid
- **JavaScript**: Interactive features and animations
- **Font Awesome**: Icon library

## Getting Started

1. Clone or download the repository
2. Open `index.html` in a web browser
3. For local development, use a local server
