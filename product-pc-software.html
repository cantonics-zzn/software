PC Host Software

Comprehensive display control software

Professional PC-based display control software for multi-projector systems and video walls.

Product Overview

Our PC Host Software provides comprehensive display control capabilities for multi-projector systems. It integrates uvMapp auto geometry correction, 3D mapping, and video wall processing into a single unified platform.

This software solution is designed for professional technicians and system integrators who need a powerful yet intuitive tool to manage complex display systems.

Core Features

Multi-projector Control

Manage multiple projectors from a single interface.

Video Wall Support

Advanced video wall processing and display management.

Screen Configuration

Flexible screen layout configuration tools.

Media Management

Comprehensive media playback and management.

Color Calibration

Advanced color matching and calibration tools.

Network Control

Remote control and monitoring capabilities.

Supported Projectors DLP, LCD, LCoS projectors
Maximum Output Unlimited display channels

Media Formats MP4, MOV, AVI, WMV, MKV, etc.
